# 🧠 AI Design

## AI Components

### 1. Risk Prediction
Predicts probability of disruptions based on location and historical data.

### 2. Fraud Detection
Detects:
- Location mismatch
- Repeated claims
- Abnormal activity

### 3. Activity Analysis
Compares:
Expected deliveries vs Actual deliveries

### 4. Smart Payout Model
Adjusts payout based on disruption severity.
